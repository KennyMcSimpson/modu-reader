Inkglass 2.3.0 — Quick Start (Windows x64)
==========================================

Thank you for using Inkglass (formerly MoDu Reader), an offline Windows
Markdown reader built for living AI, research, and repository documentation.

AUTOMATIC MIGRATION FROM MODU READER
------------------------------------
If you previously used MoDu Reader, Inkglass automatically copies your window
bounds, recent files list, live-watch, and always-on-top state
(desktop-state.json) from %APPDATA%\MoDu Reader on first launch. Your previous
MoDu Reader folder is left untouched.

HOW TO OPEN DOCUMENTS
---------------------
1. Click "Open file" (Ctrl+O), drag Markdown files into the window, or pass a
   file on the command line.
2. Click "Open folder" (Ctrl+Shift+O) to browse a repository folder in strict
   read-only mode (filter files live, sort A-Z or Recent, refresh, or close).
3. Press Ctrl+K for Quick Jump across headings, opened documents, folder files,
   and recent files.
4. Click "Paste text" (Ctrl+Shift+V) to inspect Markdown directly from the
   clipboard.
5. With the installed version, select "Inkglass" under Windows "Open with" to
   open .md files directly from File Explorer.

LIVING DOCUMENT & TECHNICAL FEATURES
------------------------------------
- Live Diff-Watch: Automatically reloads opened local files when external tools
  or AI agents edit them on disk, accumulates diffs against your baseline until
  dismissed, opens an expandable line-level Show diff drawer, supports Follow
  mode, and marks updated background documents with an unread indicator.
- Relative Links, Images & History: Resolve cross-subdirectory images
  (../images/fig.png) inside an opened folder, follow directory README.md and
  extensionless .md links, and step Back / Forward with Alt+Left / Alt+Right
  across both linked files and same-document #anchor jumps.
- Read / Split / Source: Compare rendered Markdown and raw source side-by-side
  with heading-aligned scroll sync and TOC access in Split view.
- Interactive Tools: Click any Mermaid diagram or image to zoom/pan and copy
  sanitized SVG; hover display equations or Alt+Click inline equations to copy
  raw LaTeX; hover tables to copy KaTeX-clean RFC-4180 CSV or TSV; press
  Ctrl+Shift+C to copy selected text as a clean Markdown citation.
- Export Clean PDF (Ctrl+P, light-paper print colors even in dark mode) &
  Always on Top (Ctrl+Shift+T).

PORTABLE ZIP NOTE
-----------------
If you downloaded the portable ZIP, extract the entire archive before launching
"Inkglass.exe". Keep neighboring DLL/resource files beside the executable.

PRIVACY
-------
All documents stay local in memory. No accounts, telemetry, or network uploads.
Source code and release checksums: https://github.com/KennyMcSimpson/Inkglass
