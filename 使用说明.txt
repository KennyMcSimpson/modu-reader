墨读 MoDu Reader 2.0 · Windows 桌面版
=======================================

下载：https://github.com/KennyMcSimpson/modu-reader/releases/latest
适用：Windows 10 / 11，64 位 x64。

免安装版：完整解压 ZIP 后，双击 MoDu Reader.exe。
请保留同目录下的全部文件；发给朋友时发整个 ZIP，不要只发 EXE。
安装版：运行 Setup-x64.exe，安装后从桌面或开始菜单打开。
两种版本都不需要账号、浏览器、Node.js 或 Python。

点击“打开文件”或按 Ctrl+O，也可以将 .md 文件拖到窗口。
安装后可右键 .md 文件 → 打开方式 → MoDu Reader；由你决定是否设为默认。
Ctrl+F：查找。F5：重新读取文件。Ctrl+Shift+F：专注模式。
文件 → 最近打开：重新打开最近文档，也可清空记录。
中 / EN：切换语言。Aa：调整字号、行距、字体和正文宽度。

支持 Markdown 表格、任务列表、代码高亮、LaTeX 数学与 Mermaid 图表。
支持 .md / .markdown / .mdown / .txt；文档最大 2 MB，图片最大 20 MB。
相对路径图片须位于文档同目录或子目录，如 images/photo.png。
网络图片需要联网。外部网页链接用系统默认浏览器打开。
本应用只读原文件；请使用你喜欢的编辑器修改内容，再按 F5 更新阅读。

文档正文不上传、不持久保存。粘贴文本关闭后不会保留。
设置、最近文件路径和窗口位置保存在当前用户的本机应用数据目录；
免安装版同样如此。你可以从菜单清空最近文件记录。

当前构建未进行商业代码签名，Windows 可能显示“未知发布者”。
发布页提供 SHA256SUMS.txt 供核对下载。

---------------------------------------
English
---------------------------------------
MoDu Reader 2.0 is a standalone Windows 10 / 11 x64 desktop app.

Portable: extract the ENTIRE ZIP and run MoDu Reader.exe.
Keep all runtime files together; share the complete ZIP with friends.
Installer: run Setup-x64.exe, then launch from the desktop or Start menu.
No account, browser, Node.js, or Python is required.

Ctrl+O opens documents. Drag-and-drop and pasted Markdown are supported.
The installed app is registered in Windows Open with. You choose the default.
Ctrl+F: find. F5: reload from disk. Ctrl+Shift+F: focus mode.
File > Open recent reopens files or clears recent paths.
Use 中 / EN for language and Aa for typography settings.

Tables, task lists, highlighted code, math, and Mermaid are bundled offline.
Supported: .md / .markdown / .mdown / .txt; documents up to 2 MB.
Images up to 20 MB must be in the document folder or its subfolders.
Remote images need a network connection. External links open in your browser.
The reader never edits your originals. Edit elsewhere, then press F5.

No document uploads or analytics. Document text and pasted content are not
saved on exit. Preferences, recent paths, and window bounds are stored in
local application data, including when using the portable edition.
These builds are unsigned. Windows may show an unknown-publisher notice.
SHA256SUMS.txt is available on the release page.
