# 墨读 MoDu Reader 2.0.1

本次 Windows 安全补丁更新阅读器依赖及随应用分发的 Electron 运行时，建议 2.0.0 用户更新。

This Windows security patch updates the reader dependencies and the bundled Electron runtime. Users of 2.0.0 should update.

## 更新 / Changes

- DOMPurify 更新至 3.4.17，修复 SVG 图表净化组件的已知漏洞。 / Update the SVG diagram sanitizer to DOMPurify 3.4.17.
- Markdown、Mermaid 及数学解析依赖统一使用 KaTeX 0.18.2，修复原型污染条件下的信任限制绕过。 / Use KaTeX 0.18.2 across the math dependency graph to fix a trust restriction bypass when prototype pollution is present.
- 随应用分发的 Electron 更新至 44.9.1，包含指针锁定权限归属修复及受影响证书的缓解措施。 / Ship Electron 44.9.1, including pointer-lock permission attribution fixes and mitigation for compromised certificates.
- 更新 Vite 及构建工具的安全补丁；桌面验证新增实际 Electron 版本与公式渲染检查。 / Patch Vite and build-tool dependencies, and verify the actual packaged Electron version and math rendering.

## 下载 / Downloads

- **`MoDu-Reader-2.0.1-Windows-x64.zip`**：完整解压后运行 `MoDu Reader.exe`。 / Extract the entire portable ZIP and run `MoDu Reader.exe`.
- **`MoDu-Reader-2.0.1-Setup-x64.exe`**：Windows 安装包。 / Windows installer.
- **`SHA256SUMS.txt`**：两个下载文件的 SHA-256 校验值。 / SHA-256 checksums for both downloads.

适用于 Windows 10 / 11 x64。安装包未进行商业代码签名，Windows 可能提示“未知发布者”。文档在本机只读处理。

For Windows 10 / 11 x64. These builds are unsigned, so Windows may show an unknown-publisher notice. Documents are read locally without modifying the originals.
