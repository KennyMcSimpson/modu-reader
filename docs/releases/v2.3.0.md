# Inkglass 2.3.0

A major quality-of-life and technical reading release for Inkglass — refining KaTeX extraction, PDF export, Live Diff-Watch, repository navigation, search reliability, and Split-view reading while preserving strict read-only boundaries.

## What's New in 2.3.0

- **Clean KaTeX Text Extraction & `Alt+Click` Inline Math Copy**:
  - Tables containing KaTeX formulas now export clean `$...$` / `$$...$$` Markdown math in CSV/TSV instead of duplicated MathML+HTML text.
  - Headings containing inline math render cleanly in the Table of Contents without raw TeX duplication.
  - Copy Quote with Citation (`Ctrl+Shift+C`) cleanly extracts KaTeX math in selected passages, and `Alt+Click` on any inline formula copies its raw LaTeX expression.
- **Crisp PDF Export (`Ctrl+P`)**:
  - `@media print` now forces light paper colors and light GitHub Alert / syntax highlight tokens even when exporting from Dark mode, sets `@page` margins, prevents orphaned headings (`break-after: avoid`), repeats table headers (`thead { display: table-header-group }`), and avoids clipping long code blocks or multi-page tables.
  - Eagerly decodes lazy `<img>` elements and awaits off-screen Mermaid diagrams (with bounded timeouts) before generating the PDF, and cleanly formats Source-mode documents during export.
- **Upgraded Live Diff-Watch**:
  - Accumulates changes per document against your opening/dismissed baseline across rapid external edits and manual `F5` reloads.
  - Displays `+N / -M lines · K sections changed`, adds an expandable **Show diff** line-level `- / +` drawer, adds an opt-in **Follow** toggle for incoming live updates, disambiguates duplicate heading titles (e.g., multiple `### Notes` sections) by heading index, and displays subtle unread indicators on background documents updated on disk.
- **Cross-Subdirectory Relative Images & Smarter Folder Drawer**:
  - Documents in nested subdirectories (e.g., `docs/sub.md`) can now safely load sibling relative images (`../images/fig.png`) within the active read-only folder boundary via query-encoded `inkglass-media://` URLs while preserving strict `fs.realpath` traversal and Windows junction escape blocking.
  - The Read-Only Folder drawer now includes live filename filtering, `A–Z` / `Recent` sorting, main-process-bounded Refresh, and Close folder controls.
  - Duplicate open filenames are disambiguated with parent directory segments, and the topbar breadcrumb displays folder-relative paths with a 1-click Copy Path button.
- **Smarter Find (`Ctrl+F`), `Ctrl+K` Quick Jump & Auto-Scrolling TOC**:
  - In-document Find inserts block-level separators to eliminate phantom cross-cell/cross-block matches, preserves your active match and scroll position across Mermaid lazy renders and Live Watch reloads, adds **Match Case (`Aa`)**, **Whole Word (`\b`)**, `F3` / `Shift+F3` navigation, selection seeding, and horizontal scrolling inside wide tables.
  - Added a zero-dependency **`Ctrl+K` Quick Jump** palette searching headings, opened documents, folder files, and recent files (strictly validated against the main process's recent list).
  - The active Table of Contents entry now automatically scrolls into view inside long TOC sidebars.
- **Split-View Sync, Anchor History & Repository-Friendly Links**:
  - Split view now performs smooth one-way heading-aligned scroll sync from the rendered pane to the sticky source pane, exposes the TOC popover in Split view, and keeps Source view active when switching tabs.
  - Same-document `#anchor` jumps now push your pre-jump reading position onto Back / Forward (`Alt+Left` / `Alt+Right`) history.
  - Links show URL hover previews and subtle external-link cues, and relative local links now resolve directory `README.md` targets (`./docs/`) and extensionless Markdown targets (`./guide`) strictly within the authorized folder boundary.
