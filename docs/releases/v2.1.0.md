# MoDu Reader 2.1.0

MoDu Reader 2.1.0 turns MoDu into a dedicated **offline Windows reader for living AI, research, and repository Markdown documents** — while shipping the full Electron 44.9.1 / DOMPurify 3.4.17 / KaTeX 0.18.2 security runtime updates.

## What's New in 2.1.0

### Living Document & Repository Workflow
- **Live Diff-Watch**: Automatically watches opened local files for external writes (including atomic-rename saves from editors and AI coding agents), reloads without losing your scroll position, highlights changed sections in the document and Table of Contents, and offers a **Next change** jump button. Toggleable from the topbar or **View → Live Watch External Changes**.
- **Read-Only Folder Drawer (`Ctrl+Shift+O`)**: Open any local folder to browse its Markdown tree without creating vault metadata or ever modifying source files (bounded to depth 4 / 300 files, skips `.git` and `node_modules`, blocks symlink escapes).
- **Relative `.md` Link Navigation + History**: Click relative Markdown links (`./guide.md#section`) to navigate across documents inside the authorized folder boundary, with Back/Forward toolbar buttons and `Alt+Left` / `Alt+Right` shortcuts.
- **Read / Split / Source View**: Inspect rendered Markdown side-by-side with raw source.
- **Persistent Reading Positions**: Automatically saves and restores scroll position per document path across restarts.

### Interactive Technical Reading Tools
- **Native YAML Frontmatter Cards**: Collapsible metadata header for documents with leading `---` frontmatter.
- **5 GitHub Alerts**: Styled callout cards for `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, and `[!CAUTION]`.
- **Interactive Mermaid & Image Lightbox**: Click any diagram or image to zoom, pan, and copy sanitized SVG directly to the clipboard.
- **1-Click Copy Raw LaTeX (`TeX`)**: Hover any display math block to copy its original TeX source.
- **1-Click Table Export (`CSV` / `TSV`)**: Hover any GFM table to copy RFC-4180 CSV or spreadsheet TSV.
- **Copy Quote with Citation**: Format selected text (or the current heading) as a Markdown blockquote with source filename and section.
- **Export Clean PDF (`Ctrl+P`) & Always-on-Top Pin (`Ctrl+Shift+T`)**.

### Pure English UI & Security Runtime
- Streamlined pure English interface, menus, installer, and built-in guides.
- Ships Electron **44.9.1**, DOMPurify **3.4.17**, KaTeX **0.18.2**, and Vite **8.1.6** security patches, plus versioned release-notes and runtime version verification in CI.

## Downloads

- **`MoDu-Reader-2.1.0-Setup-x64.exe`**: Per-user Windows installer with **Open with** registration.

For Windows 10 / 11 x64. Builds are unsigned, so Windows may display an unknown-publisher notice. All documents are handled locally and read-only.
