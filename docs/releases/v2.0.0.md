# MoDu Reader (now Inkglass) 2.0.0

MoDu Reader (now Inkglass) is a standalone Windows desktop application. No browser, Node.js installation, or account is required to use it.

## Downloads

- **`MoDu-Reader-2.0.0-Windows-x64.zip`**: Portable build. Extract the entire archive and run `MoDu Reader.exe`. Share the full ZIP to pass it along.
- **`MoDu-Reader-2.0.0-Setup-x64.exe`**: Windows installer. Adds Start menu and desktop shortcuts and registers MoDu Reader in Windows **Open with**.
- **`SHA256SUMS.txt`**: SHA-256 checksums for the release files.

Targets Windows 10 / 11 (64-bit x64). These builds are unsigned, so Windows may display an unknown-publisher prompt.

## Desktop Features

- Standalone window, native open-file dialog, drag-and-drop, and command-line file opening
- Recent files list, `F5` reload, and `Ctrl+F` find
- Automatic loading of relative images inside the document folder
- Bilingual UI, table of contents, themes, syntax highlighting, math formulas, and Mermaid diagrams
- Read-only document handling with zero uploads

Choose your default file handler in Windows directly. For the portable build, keep all neighboring runtime files alongside `MoDu Reader.exe`. Remote images still require a network connection. Reading preferences, recent file paths, and window bounds are stored in the local application data directory.
