墨读现在是可独立运行的 Windows 桌面应用，运行时不需要浏览器、Node.js 或账号。

MoDu Reader is now a standalone Windows desktop application. No browser, Node.js, or account is required to use it.

## 下载 / Downloads

- **`MoDu-Reader-2.0.0-Windows-x64.zip`**：免安装版。完整解压后运行 `MoDu Reader.exe`。把整个 ZIP 发给朋友即可。
- **`MoDu-Reader-2.0.0-Setup-x64.exe`**：安装版。带开始菜单和桌面快捷方式，可在 Windows“打开方式”中选择墨读。
- **`SHA256SUMS.txt`**：下载文件的 SHA-256 校验值。

Windows 10 / 11，64 位 x64。安装包尚未进行商业代码签名，Windows 可能提示“未知发布者”。

For Windows 10 / 11 x64. Extract the **entire ZIP** and launch `MoDu Reader.exe`, or use the Setup installer. The installer adds Start menu and desktop shortcuts and registers MoDu in **Open with**. These builds are unsigned, so Windows may show an unknown-publisher notice.

## 桌面功能 / Desktop features

- 独立窗口、系统打开文件对话框、拖放、命令行打开 / Standalone window, native open dialog, drag-and-drop, command-line opening
- 最近打开记录、F5 重新读取、Ctrl+F 查找 / Recent files, F5 reload, Ctrl+F find
- 自动读取文档文件夹内的相对路径图片 / Relative images inside the document folder
- 中英界面、目录、主题、代码高亮、数学公式、Mermaid 图表 / Bilingual UI, contents, themes, code, math, Mermaid
- 原文件只读，文档不上传 / Read-only documents; no uploads

文件默认打开方式由你在 Windows 中选择。免安装版需要保留 EXE 旁边的所有运行文件。网络图片仍需要联网。阅读偏好、最近文件路径和窗口位置保存在本机应用数据目录。

Choose the default file handler in Windows yourself. Keep the portable EXE and all its neighboring runtime files together. Remote images require a network connection. Preferences, recent file paths, and window bounds are stored in local application data.
