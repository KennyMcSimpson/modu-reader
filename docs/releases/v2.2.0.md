# Inkglass 2.2.0

**MoDu Reader is now Inkglass** — a clean international identity for the offline Windows Markdown reader built for living AI, research, and repository documentation.

## What's New in 2.2.0

- **New Identity (`Inkglass`)**: Rebranded Windows executable (`Inkglass.exe`), portable archive (`Inkglass-2.2.0-Windows-x64.zip`), per-user NSIS installer (`Inkglass-2.2.0-Setup-x64.exe`), Windows **Open with** registration (`Inkglass.Markdown`), window titles, custom media protocol (`inkglass-media://`), and documentation.
- **Automatic Non-Destructive State Migration**: On first launch, Inkglass automatically copies your existing `desktop-state.json` (window bounds, recent file paths, live-watch, and always-on-top state) from `%APPDATA%\MoDu Reader` into `%APPDATA%\Inkglass` without touching your previous folder (standalone HTML builds also inherit legacy browser `localStorage` keys).
- **Includes all 2.1.0 Living-Docs & Security Features**: Live Diff-Watch with scroll preservation and section-change highlights, Read-Only Folder drawer (`Ctrl+Shift+O`), relative `.md` link traversal + Back/Forward history, YAML Frontmatter cards, 5 GitHub Alerts, Mermaid/Image zoom-pan lightbox + Copy SVG, 1-click raw LaTeX copy, RFC-4180 CSV/TSV table copy, Quote with Citation, Split view, Export PDF (`Ctrl+P`), Always-on-Top (`Ctrl+Shift+T`), and Electron 44.9.1 / DOMPurify 3.4.17 / KaTeX 0.18.2.

## Downloads

- **`Inkglass-2.2.0-Windows-x64.zip`**: Portable build — extract all files and run `Inkglass.exe`.
- **`Inkglass-2.2.0-Setup-x64.exe`**: Per-user Windows installer with **Open with** registration.
- **`SHA256SUMS.txt`**: SHA-256 checksums for both artifacts.

For Windows 10 / 11 x64. Builds are unsigned, so Windows may display an unknown-publisher notice. All documents are handled locally and read-only.
